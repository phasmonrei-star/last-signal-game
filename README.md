1. Сценарий 1 - победа (сбор ресурсов, ремонт и SOS):
	• Ввод: 1 (3 раза подряд для сбора 3 ед. металлолома) -> 2 (возврат в Центральный отсек) -> 4 (ремонт передатчика) -> 5 (отправка SOS)
	• Результат: передатчик починен, выводится экран победы и итоговая статистика
2. Сценарий 2 - поражение (исчерпание кислорода) и предупреждения:
	• Ввод: 1 (или чередование 1 и 2 13 раз подряд без отправки SOS)
	• Результат: при O2 <= 50 появляется жёлтое предупреждение, при O2 <= 24 - критическое предупреждение, на 0 O2 игра завершается экраном поражения
3. Сценарий 3 - лечение и проверка неверного ввода:
	• Ввод: 9 или abc (проверка ветви default и защиты от некорректного ввода) -> 1 (до срабатывания события с травмой -25 HP) -> 3 (использование аптечки, восстановление +25 HP без превышения 100)
4. Сценарий 4 - досрочный выход:
	• Ввод: 0 (или exit/q) на любом ходу
	• Результат: штатное завершение цикла с выводом прощального сообщения и статистики ходов
